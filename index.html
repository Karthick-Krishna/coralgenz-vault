CORALGENZ VAULT USER & SECURITY GUIDE

🛡️ ZERO-TRUST ARCHITECTURE

Coralgenz Vault performs 100% of cryptographic operations within the isolated sandbox of your web browser. Neither passwords nor plaintext files are ever transmitted to any external server.

🔐 ENCRYPTION STANDARD

Each file receives a distinct 256-bit AES-GCM data key wrapped using PBKDF2 with 600,000 SHA-256 iterations and unique 128-bit cryptographic salt and initialization vectors (IV).

📤 STANDALONE PROTECTED HTML PACKAGES

When you protect or export a file, you can download it as a .secure.html package. This self-contained digital fortress file includes:

  • The encrypted payload blob
  • A lightweight, zero-dependency browser decryptor
  • Enforced credential authentication policy (Always Ask Password)
  • No internet connection required for decryption

🚨 PANIC EMERGENCY TRIGGER

In high-risk environments, tap the red PANIC button in the top navigation bar to immediately lock the screen or scrub sensitive in-memory payloads according to your settings.
